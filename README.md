# Бюджет — личный планировщик

PWA-приложение: открывается в браузере, ставится на главный экран телефона, работает офлайн.
Все данные хранятся только на телефоне (IndexedDB); с PIN-кодом шифруются AES-256.

## Как выложить, чтобы открыть на телефоне

Приложению нужен HTTPS-адрес (иначе не будет установки и шифрования). Проще всего бесплатно:

**Вариант 1 — Netlify (без командной строки)**
1. Зарегистрируйся на https://app.netlify.com
2. «Add new site» → «Deploy manually» → перетащи эту папку целиком.
3. Получишь адрес вида `https://имя.netlify.app` — открой его на телефоне.

**Вариант 2 — GitHub Pages**
1. Создай репозиторий на GitHub, загрузи туда все файлы этой папки.
2. Settings → Pages → Branch: `main` / root → Save.
3. Адрес: `https://<логин>.github.io/<репозиторий>/`.

Сайт — это только файлы приложения. Твои операции на сервер не попадают.

## Установка на телефон
- **iPhone:** открой адрес в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** открой в Chrome → ⋮ → «Установить приложение».

## Банки
| Банк | Как подключается |
|---|---|
| Monobank | Автоматически через личный токен с https://api.monobank.ua (только чтение) |
| Privat24 | Импорт выписки PDF, Excel или CSV (открытого API для физлиц у Привата нет) |
| Bank Pekao | Импорт выписки CSV из Pekao24 |
| Revolut | Импорт выписки CSV/Excel |
| Trust Wallet / крипта | Пока счёт «Крипто» с ручным балансом |
| Любой другой | Импорт CSV/Excel с ручной настройкой столбцов |

## Локальный запуск
```bash
python3 -m http.server 8765
```
и открыть http://localhost:8765

## Структура
- `index.html`, `css/app.css` — оболочка и стили (светлая/тёмная тема)
- `js/app.js` — интерфейс
- `js/store.js` — данные, шифрование, валюты
- `js/cats.js` — категории и автокатегоризация (MCC + ключевые слова)
- `js/insights.js` — статистика, подписки, умные подсказки
- `js/importer.js` — импорт выписок; `js/mono.js` — Monobank API
- `js/i18n.js` — русский и английский
- `sw.js`, `manifest.webmanifest`, `icons/` — PWA
